# 🚀 Getting Started

## Prerequisites

Make sure you have:

* Node.js v18+
* npm

---

## 📥 Clone Repository

```bash
git clone https://github.com/purumeswarteja/InterviewPro-AI.git

cd InterviewPro-AI
```

---

## ⚙️ Backend Setup

```bash
cd backend

npm install

npm run dev
```

Backend runs on:

```text
http://localhost:4000
```

---

## 🎨 Frontend Setup

Open another terminal:

```bash
cd frontend

npm install

npm run dev
```

Frontend runs on:

